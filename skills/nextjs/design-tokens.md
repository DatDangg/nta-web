### Usage rules (khóa màu — taste-skill §4.2)

- **1 accent duy nhất** = `#0071E3` cho toàn site (CTA/link/focus/active-nav). Không đổi accent giữa trang.
- Semantic `error/success/warning` **chỉ cho form + trạng thái**; text trạng thái bắt buộc dùng `*-ink`.
- Badge/tag trạng thái: nền tint (`color-mix` 10%) + text `*-ink`, KHÔNG nền màu đặc + text trắng.
- Không gradient text, không neon/glow, không pure black `#000` (text đã là `#1D1D1F`).
- Light-only: trang khóa theme light (không dark mode ở v1) — toàn bộ trang 1 theme, section chỉ đổi nền
  trong cùng family (`#FFFFFF` ↔ `#F5F5F7`).

## 2. Typography (fluid clamp — R-23 "ưu tiên fluid")

**Font stack (docs/DESIGN.md):**

```css
--font-sans:
  var(--font-inter),            /* next/font Inter (subset vietnamese + latin) */
  -apple-system, BlinkMacSystemFont, "SF Pro Display", "Segoe UI", Roboto,
  "Helvetica Neue", Arial, sans-serif;
--font-mono: ui-monospace, "SF Mono", "JetBrains Mono", Menlo, monospace; /* chỉ code/data */
```

- Load Inter bằng **`next/font/google`** (`display: swap`, subsets `["latin","vietnamese"]`), KHÔNG link `<link>` Google Fonts.
- SF Pro/system trước cho vibe Apple trên thiết bị Apple; Inter fallback hỗ trợ tiếng Việt (diacritics).
- Inter là lựa chọn có chủ đích của brief (brand chỉ định Inter/SF Pro) — không phải default lười của LLM.

**Scale (clamp, đã chốt 48–96px cho hero):**

```css
:root {
  --text-hero:    clamp(3rem,   2.25rem + 3.75vw, 6rem);    /* 48 → 96px  hero home */
  --text-display: clamp(2.5rem, 2rem + 2.5vw,    4rem);      /* 40 → 64px  H1 PageHeader */
  --text-h2:      clamp(2rem,   1.75rem + 1.25vw, 2.5rem);   /* 32 → 40px  section title */
  --text-h3:      clamp(1.375rem, 1.25rem + 0.5vw, 1.5rem);  /* 22 → 24px  card title */
  --text-body-lg: clamp(1.0625rem, 1rem + 0.3vw, 1.125rem);  /* 17 → 18px  intro/lead */
  --text-base:    1rem;                                      /* 16px body (line-height 1.5) */
  --text-sm:      0.875rem;                                  /* 14px label, caption */
  --text-xs:      0.75rem;                                   /* 12px meta, hint */
}
```

| Weight | Value | Usage |
|---|---|---|
| `--weight-normal` | 400 | body |
| `--weight-medium` | 500 | nav, button, label |
| `--weight-semibold` | 600 | H3, card title, bài viết Strong |
| `--weight-bold` | 700 | H1/H2, hero |

**Quy tắc:**
- Base 16px; body `line-height: 1.5`; heading `line-height: 1.12` (≥1.1 để dấu tiếng Việt không chạm nhau);
  hero `tracking: -0.02em` (chỉ Latin — dấu tiếng Việt không bị compact quá mức, KHÔNG dùng `tracking-tighter`).
- Body measure `max-width: 65ch` (article: 720px). KHÔNG px cho font-size → dùng rem/clamp.
- KHÔNG uppercase+letter-spacing rộng cho chuỗi tiếng Việt có dấu ở size < 14px (dấu chồng).
- Hero discipline: title ≤ 2 dòng, subtext ≤ 20 từ / ≤ 4 dòng, tối đa 4 text element
  (headline + subtext + 2 CTA), `pt-24` cap, CTA luôn thấy ngay.

## 4. Border Radius (shape lock — taste-skill §4.4, rule có ghi rõ)

```css
--radius-sm:   4px;    /* input, tag, badge nhỏ */
--radius-md:   8px;    /* button (pill? xem dưới), card thường, ảnh card */
--radius-lg:   16px;   /* feature card, section card, modal, hero image */
--radius-full: 9999px; /* avatar, dot, pill */
```

**Rule áp dụng mọi nơi (vi phạm = broken design):**
- **Button = pill** (`rounded-full`) — Apple-style; mọi button cùng radius.
- **Input/textarea/tag = `rounded-sm` (4px)**.
- **Card thường = `rounded-md` (8px)**; feature/section-level card + modal + ảnh hero = `rounded-lg` (16px).
- Không trộn radius ngoài bảng này.

## 6. Motion (subtle — brief "animation subtle"; taste-skill §5/§6)

```css
--duration-fast: 150ms;   /* hover, focus */
--duration-base: 250ms;   /* toggle, drawer, state change */
--duration-slow: 400ms;   /* scroll reveal */
--ease-out:  cubic-bezier(0.16, 1, 0.3, 1);    /* expo-out, mặc định mọi transition */
--ease-in-out: cubic-bezier(0.4, 0, 0.2, 1);
```

| Motion | Spec | Lý do (motivated) |
|---|---|---|
| Scroll reveal | `opacity 0→1` + `translateY(16px→0)`, 400ms `--ease-out`, stagger 60ms, `once: true` | hierarchy: nội dung vào theo thứ tự đọc |
| Button hover/active | bg → `primary-hover`; `:active` `scale(0.98)` 150ms | feedback cảm ứng |
| Card hover | `-translateY(4px)` + `--shadow-sm`, 250ms | affordance click |
| Drawer/Modal | fade scrim + slide 250ms | state transition |
| Logo đối tác (`/about`) | grayscale → color, 250ms | feedback hover |

- Library: hover/reveal bằng **CSS transition + `motion/react`** (`whileInView`, `useReducedMotion`) —
  isolate trong client leaf `'use client'`; **cấm** `window.addEventListener('scroll')`.
- **`prefers-reduced-motion: reduce`** → mọi reveal về static tức thì (bắt buộc, R-24).
- Animate chỉ `transform` + `opacity`. Không marquee, không parallax, không scroll-hijack,
  không confetti, không autoplay video có tiếng, không infinite loop trang trí.

## 11. i18n strings pattern (R-20)

```text
src/i18n/routing.ts          # locales: ['vi','en'], defaultLocale: 'vi'
src/i18n/messages/vi.json    # nguồn mặc định
src/i18n/messages/en.json
src/app/[locale]/...         # / = VI, /en/... = EN
```

- Key pattern namespace: `nav.*`, `footer.*`, `common.*`, `home.*`, `about.*`,
  `solutions.enterprise.*`, `solutions.ai.*`, `products.*`, `caseStudies.*`, `blog.*`, `contact.*`, `notFound.*`.
- Component dùng `useTranslations('<ns>')`; content dài (bài, case) nằm MDX riêng 2 folder `vi/`, `en/`.
- **Một label cho mỗi intent** (taste-skill: cấm CTA trùng intent) — canonical:

| Intent key | VI (mặc định) | EN |
|---|---|---|
| `common.cta.contact` | Liên hệ tư vấn | Contact us |
| `common.cta.viewSolutions` | Xem giải pháp | View solutions |
| `common.cta.learnMore` | Tìm hiểu thêm | Learn more |
| `common.cta.viewCaseStudies` | Xem case study | View case studies |
| `common.cta.submit` | Gửi yêu cầu | Send request |

- EN pattern: cùng cấu trúc, sentence case (KHÔNG ALL CAPS), độ dài ≤ VI + 30%;
  hreflang `vi` / `en` + `x-default` → `vi` (R-20).
- Số/diện tích/ngày tháng theo locale (`Intl.NumberFormat`/`DateTimeFormat`).
