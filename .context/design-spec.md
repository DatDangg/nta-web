## 1. Global Patterns (áp dụng mọi screen)

### 1.1 App shell — Header (R-11)

- Sticky top (`--z-header`), cao **64px mobile / 72px desktop** (cap 80px), nền `background` + `backdrop-blur`
  sau khi scroll, border-bottom `--color-border` mảnh.
- Desktop (≥1024px): logo (trái, text wordmark "NTA" khi chưa có logo OQ#1) · nav ngang 1 dòng
  (Giải pháp [dropdown enterprise/AI] · Sản phẩm · Case Study · Tin tức · Về NTA · Liên hệ) ·
  language toggle `VI | EN` · CTA "Liên hệ tư vấn" (button pill, sm).
- Mobile (<1024px): logo + hamburger. Drawer full-height bên phải: nav list + language toggle + CTA,
  slide-in 250ms + scrim `--color-overlay`.
- Active route: text `primary` + underline 2px. Dropdown desktop: hover + focus (keyboard), `aria-expanded`.

### 1.2 App shell — Footer (R-11, BR-001)

- Nền `background-alt`, 4 cột desktop / 2 cột tablet / 1 cột mobile (nhóm accordion tuỳ chọn):
  **Về NTA** · **Giải pháp** (Enterprise + 4 slug, AI + 3 slug) · **Nội dung** (Sản phẩm, Case Study, Tin tức) ·
  **Liên hệ** (hotline/email/địa chỉ placeholder + social icons + `VI|EN`).
- Cột trái/biên: block CTA "Liên hệ tư vấn" (BR-001: mọi trang có CTA liên hệ ở footer).
- Legal line: copyright + link Chính sách (nếu có). KHÔNG version footer, không chuỗi meta trang trí.

### 1.3 Section & layout-family system (taste-skill §4.7)

- Section padding `py-12 md:py-16 xl:py-24`, nền xen kẽ `background` ↔ `background-alt` (theme lock light).
- **Mỗi trang ≥ 4 layout family**, cấm 3 section liên tiếp cùng family, cấm lặp "grid card" 2 lần/trang.
- **Cấm eyebrow/kicker/section-number** trên heading (impeccable refuse list) — heading tự gánh weight.
- Cấm scroll cue (`Cuộn để xem`), cấm em-dash (`—`) trong mọi chuỗi UI, cấm middle-dot trang trí hàng loạt.
- CTA: 1 label cho mỗi intent (xem tokens §11), không 2 CTA cùng intent trên 1 trang, không wrap ở desktop.
- Card chỉ khi elevation thật sự cần; nếu không → dùng spacing/divider.
- Container: `max-w-[1280px] mx-auto px-4 sm:px-6 lg:px-8`.

### 1.4 States policy

| Loại | Policy v1 (SSG, không fetch ở page level) |
|---|---|
| **Loading trang** | SSG → **không có page-level skeleton** (đề xuất chốt cho R-01). Ảnh giữ đúng `aspect-ratio` + skeleton nền `surface-sunken` để CLS < 0.1. |
| **Loading động** | Chỉ form submit: nút chuyển "Đang gửi…" + spinner 16px, `aria-busy`. |
| **Error** | Form: inline error dưới field (`error-ink`) + summary trên form; 429 → 1 thông báo rate-limit. Ảnh lỗi → fallback nền `surface-sunken`. |
| **Empty** | Filter/pagination không có kết quả → message + nút "Xóa bộ lọc". Section phụ không có content (related, download, logo) → **ẩn section**, không để trống. |
| **404** | Slug sai (`enterprise/[slug]`, `ai/[slug]`, `case-studies/[slug]`, `blog/[slug]`) → `not-found.tsx` (Screen 13). |

### 1.5 Motion policy

- Reveal khi scroll: fade + slide 16px, 400ms, stagger 60ms, `once` (tokens §6), chỉ `transform/opacity`.
- Hover: button `primary-hover` + active `scale(0.98)`; card lift `-4px` + `shadow-sm`; logo grayscale → màu.
- Drawer/modal 250ms. **`prefers-reduced-motion` → static.** Motion client-leaf `'use client'` (motion/react).
- Cấm: parallax, marquee, scroll-hijack, autoplay video tiếng, hiệu ứng sinh nhật/confetti.

### 1.6 A11y global (R-24, WCAG 2.1 AA)

- Focus ring global 2px `--color-focus` offset 2px (trên nền primary: ring trắng + viền ngoài primary).
- Landmark: `header/nav/main/footer`; 1 `h1`/trang; heading hierarchy đúng thứ tự; skip-link "Bỏ qua tới nội dung".
- Touch target ≥ 44×44px (nav, filter pill, icon button, pagination).
- Alt: ảnh nội dung = mô tả ngắn VI/EN; ảnh trang trí `alt=""`; iframe `title`.
- Form: `label` visible (không placeholder-as-label), error `aria-describedby` + `aria-invalid`,
  success `role="status"`, error summary `role="alert"`.
- Drawer/modal: focus trap, `Esc` đóng, trả focus về trigger, `aria-expanded/controls/labelledby`.
- Contrast theo bảng tokens §1; semantic text dùng `*-ink`. Không info truyền đạt riêng bằng màu
  (kèm icon/chữ).

### 1.7 i18n & copy (R-20)

- VI mặc định (`/`), EN ở `/en/...`; toggle `VI | EN` ở header (và footer), link `hreflang` 2 chiều + `x-default: vi`.
- Key namespace + canonical CTA labels theo tokens §11. Content dài = MDX 2 bản `vi/` + `en/`.
- Copy tone VI: trung tính, rõ nghĩa, không slogan rỗng (cấm "Elevate/Seamless/Đột phá"), câu ≤ 2 dòng.
- EN pattern: dịch sát nghĩa, sentence case, ≤ VI + 30% độ dài. Không ALL CAPS chuỗi có dấu tiếng Việt.
- Số liệu case study chỉ dùng số thật từ content (cấm số bịa 99.9%); BR-004: tên khách hàng chỉ khi được phép,
  không thì anonymize ("một chuỗi phòng khám nha khoa tại Tây Nam Bộ").

### 1.8 SEO global (R-21)

- Title template: `"%s | NTA"` (không lặp brand 2 lần, ≤ 60 ký tự); `metadataBase` = `https://ntavietnam.tech`.
- Mỗi route: `title` + `description` (150–160 ký tự) + `alternates.languages {vi, en, x-default}` +
  OpenGraph (`locale vi_VN/en_US`, ảnh OG 1200×630 OG-site) + Twitter card.
- JSON-LD: **Organization + WebSite** (root layout, 2 locale) · **BreadcrumbList** (trang con) ·
  **Article** (blog detail) · **ContactPage** (contact). `sitemap.xml` + `robots.txt` (R-21).
- Ảnh hero `priority`, ảnh còn lại `loading="lazy"` (R-22). Lighthouse SEO/Performance ≥ 90.

### 1.9 Component library (docs/DESIGN.md → implementation)

`Button` (primary/secondary/ghost/outline, sm/md/lg, pill) · `Input/Textarea` (label + helper/error) ·
`Card` (SolutionCard/ProductCard/CaseStudyCard/PostCard, hover lift) · `Section` (default/alt/accent) ·
`Badge` · `Timeline` · `Nav` (desktop/mobile) · `Breadcrumb` · `PageHeader` · `CTABanner` · `Pagination` ·
`FilterBar`. Icon: Phosphor SVG, 1 family. MDX body: `@tailwindcss/typography` `prose` + override token.
File component ≤ 300 dòng, function ≤ 50 dòng → tách sub-component khi vượt.
